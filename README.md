# Vault Gallery

Защищённая офлайн-галерея для Android.

## Основные возможности

* Маскировка под калькулятор
* Секретный код: 2580=
* Пароль для входа
* Хранение фото и видео
* Вложенные папки
* Один файл может находиться в нескольких папках
* Ручная сортировка
* Сортировка по дате добавления
* Шифрование файлов
* Полностью офлайн

## План разработки

### Версия 0.1

* Калькулятор
